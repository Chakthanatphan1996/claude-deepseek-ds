# Workflow: Claude วางแผน → DeepSeek ลงมือ → Claude ตรวจ

## 0. เตรียมโปรเจกต์
- ทำงานใน git repo เสมอ (`git init`) — ถ้า `ds` ทำพัง ย้อนได้
- ใส่ `CLAUDE.md` ที่ root (ดู `templates/CLAUDE.md`) — ทั้ง `claude` และ `ds` อ่านไฟล์นี้

## 1. วางแผนด้วย Claude
```
claude
> อ่านโปรเจกต์นี้ แล้วเขียน PLAN.md สำหรับ <งาน> ตาม templates/PLAN.md
> แตกเป็นขั้นที่แต่ละขั้นทำเสร็จและเทสได้ในตัว ระบุไฟล์ที่ต้องแตะ และเกณฑ์ผ่าน
```
อ่าน PLAN.md เอง แก้จนพอใจ แล้ว commit

## 2. ลงมือด้วย DeepSeek
```
ds
> ทำตาม PLAN.md ทีละขั้น
> ทุกขั้น: เขียนโค้ด → รันเทส → ผ่านแล้ว commit ด้วยข้อความ "step N: ..."
> ถ้าขั้นไหนต้องเปลี่ยนแผน ให้หยุดและเขียนเหตุผลใน PLAN.md อย่าเดาเอง
```

## 3. ตรวจด้วย Claude
```
claude
> รีวิว git diff <commit ก่อนเริ่ม>..HEAD เทียบกับ PLAN.md
> หา: บั๊ก, เคสที่ไม่ได้เทส, ความปลอดภัย, โค้ดที่ไม่ได้อยู่ในแผน
```
แก้เองหรือส่งรายการกลับไปให้ `ds` แก้ แล้วตรวจซ้ำ

## เคล็ดลับ
- ขั้นยิ่งเล็ก DeepSeek ยิ่งพลาดน้อย
- ให้ `ds` เขียนเทสก่อนโค้ด (TDD) ช่วยกันหลงทาง
- งานสั้น ๆ แก้บรรทัดเดียว ใช้ `claude` เลยเร็วกว่า
